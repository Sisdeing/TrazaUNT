# Datos históricos reales — TrazaUNT 4.0

## Fuentes y cobertura
Archivos entregados por el usuario: `peru_oece_bulk_2020` a `2024` (JSONL.GZ), adjudicaciones directas 2021–2026, contratos 2024–2026, desiertos 2026, miembros de comité 2026, proveedores 2025–2026, CID2026 y diccionario. Los archivos OCDS contienen versiones compiladas, incluso procesos iniciados antes del año del archivo. Se conservaron 11 604 OCID únicos de 51 entidades universitarias identificadas por nombre. De ellos 493 pertenecen a UNT. Después de vincular Excel por código exacto de convocatoria hay 529 procedimientos únicos; se agrega una ficha pública de la versión anterior que no aparece en los archivos recibidos. La distribución incluye 530 expedientes públicos y 2 de demostración. No se infiere adjudicación de todos los ítems a partir de un ítem, ni pago por la existencia de un contrato. Los importes por ítem y contrato se mantienen como evidencia, no se suman indiscriminadamente.

## Procesamiento
1. `scripts/extraer_universidades.py CARPETA`: extracción por comprador y deduplicación OCID conservando la versión de fecha más reciente.
2. `scripts/integrar_historico.py ARCHIVO_ZIP`: cruzar Excel por código de convocatoria (1894 es código de entidad observado en OCDS/Excel), código de contrato o RUC según corresponda. El parser usa las cadenas compartidas y la primera hoja del formato XLSX observado. No es un lector universal de Excel. No se incluye todo el dataset nacional original. Las filas no vinculadas se excluyen. CID2026 no devolvió registros de UNT con el filtro de entidad/RUC; no se simulan asientos. El diccionario se conserva como fuente de consulta.
3. `scripts/analizar_historico.py`: Isolation Forest por categoría, 150 árboles, contaminación 0.05, semilla 42; log1p(monto PEN) y log1p(postores). Se excluyen datos faltantes, moneda no PEN y años anteriores a 2020; entrenamiento 2020–2023, prueba temporal 2024. Puntuación de atipicidad relativa al entrenamiento, sin etiqueta de corrupción. El score de entrenamiento no equivale a una prueba independiente. No se reporta accuracy, F1 ni probabilidad de fraude. Las tasas de señal pueden cambiar por deriva y muestras pequeñas. 430 expedientes UNT puntuados, 57 señales (incluye entrenamiento y prueba). No son alertas TZ confirmadas. El script calcula resultados reproducibles; la app muestra resultados precomputados, no reentrena al abrir.
4. Al iniciar se importan expedientes y eventos publicados. Cada fase conserva su estado local sin verificar. `cobertura_ocds.json`, `cobertura_complementaria.json`, `analisis_historico.json` contienen conteos auditables.

## Limitaciones
Los Excel complementarios no contienen todos los procedimientos ni todas las actuaciones de 2025–2026. No se recibió OCDS 2025/2026 ni MEF. No se descargaron los PDF enlazados ni se acreditaron vistos buenos, pagos o conformidades. Los nombres ficticios de los dos casos de demostración no se aplican a registros reales. La plantilla de fases es orientativa, no acredita requisitos legales específicos. Los módulos heredados de contratación/alertas/predicción/concesiones/portal público mantienen la base sintética; la información real se consulta en Expedientes y trazabilidad. No conectar a un entorno institucional sin revisión de seguridad y permisos. La app usa la vista HTML integrada y React precompilado de 3.3; no se afirma una validación visual E2E.
